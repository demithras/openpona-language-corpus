# Provenance of this consolidation

This repository was consolidated on 2026-09-29 from several layers of project history.

## Primary surviving project artifacts

- `OpenPona_LINJA_Corpus_2026-09-21.zip` — the strongest previous consolidated OpenPona/LINJA corpus, including `openpona_anu_1_1.md`, grammar, conflict ledger and evidence ledger.
- `core42_thoth_report.md` and earlier Core42 matrix artifacts — historical sources for matrix development; superseded where they conflict with later canon.
- previous Operational Ontology POC/Round 2 specification packs — evidence for the separation between OpenPona and EOO core architecture.

## Conversation-derived decisions after the 2026-09-21 corpus

The following later decisions are incorporated because they were explicitly accepted in subsequent work:

- each token is first a vector/verb/direction;
- META/repetition has parse priority;
- structural tokens are structural only in structural position and otherwise retain vector semantics (superseded 2026-09-30: only `tan` is dual, see `history/supersession_ledger.md`);
- 3+ semantic units in one concept require `pi` grouping (shaped 2026-09-30: head of 1–2 units, groups of exactly two);
- derivative algebra for repeated semantic units;
- the single-header matrix hypothesis was rejected;
- weak external-coordinate/embedded-header model gained strong internal support while exact lexical generation remained unproven;
- OpenPona-as-required-EOO-core was weakened/rejected; EOO independence was supported;
- OpenPona is now tested as a candidate Ontology Language rather than assumed to be one.

## Provenance policy

A future editor should prefer the latest explicit decision over older source artifacts, but must preserve the superseded artifact in history rather than erasing it.
