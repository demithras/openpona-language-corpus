# Contributing

Changes fall into three categories:

## Canon change

Requires:

- explicit statement of the current rule;
- falsifiable reason to replace it;
- research evidence or author decision;
- update to supersession ledger;
- integrity-test update;
- versioning decision if token inventory/semantics materially change.

## Research addition

May add a hypothesis, experiment, rival, falsifier or result without changing canon. Clearly mark status.

## Historical addition

Preserve old artifacts accurately. Never let an old matrix silently override current canon.
