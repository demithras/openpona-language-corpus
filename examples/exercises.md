# Exercises and answer key

## 1. Matrix recall

Find the token at:

1. row 3 / Mercury;
2. row 4 / Moon;
3. row 5 / Jupiter;
4. row 6 / Saturn.

**Answers:** `lawa`, `ante`, `tenpo`, `anu`.

## 2. Canon check

Which are canonical OpenPona primitives?

```text
mute  ken  kalama  anu  nimi  linja
```

**Answer:** `ken`, `anu`, `linja`.

## 3. Address safety

An address resolves to two candidates. Which action is valid?

A. choose the newest object;  
B. choose the most frequently used;  
C. return ambiguity and narrow context;  
D. add a new primitive word.

**Answer:** C.

## 4. Truth status

A user asks an agent to transfer inventory. The agent has not executed anything. Is the transfer an observation?

**Answer:** No. It is at most requested/intended/proposed. Execution and observed outcome are separate.

## 5. Function/Action research boundary

Can the language corpus itself prove that `Function != Action` is enforceable in an EOO runtime?

**Answer:** No. It can express the distinction as a research target; enforcement belongs to the runtime experiment.
